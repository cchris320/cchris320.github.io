方向修正

原本的「MediaPipe 姿勢分析推薦痛點」已取消作為產品方向。姿勢不等於疼痛，網頁不應推測使用者痛源。MediaPipe 改放到健身模式，用於它更擅長的骨架偵測與動作姿勢檢查。

雙模式架構

放鬆模式

  1. 使用者選痛點：SVG 肌肉圖 / 症狀快選
  2. 選擇器材：徒手、滾筒、按摩球、彈力帶、筋膜槍
  3. 查看放鬆方法：GIF、步驟、時間、注意事項
  4. 按壓位置確認：感覺不對時顯示相鄰肌群

健身模式

  1. 選擇訓練動作
  2. 查看動作教學與常見錯誤
  3. 啟動攝影機
  4. MediaPipe 骨架偵測與 form check

主要流程

模式切換：放鬆 / 健身 ↓ 放鬆模式： 選痛點或症狀 → 選器材 → 看方法卡片 → 按壓位置確認 ↓ 感覺不對 → 顯示相鄰肌群 健身模式： 選動作 → 看教學卡片 → 啟動攝影機 → MediaPipe form check ↓ 初版：二頭彎舉

展示說法

我們一開始考慮用 MediaPipe 分析姿勢並推薦痛點，但後來發現姿勢不等於病痛，這會造成過度判斷。因此我們重新設計成雙模式：放鬆模式由使用者主動選擇痛點，並透過按壓位置確認修正；健身模式則使用 MediaPipe 做它真正擅長的骨架偵測與動作姿勢檢查。
