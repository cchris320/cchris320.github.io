## Tier 1 — 新增（最優先查證）

### hip_flexor 髖屈肌

- [ ] **hands** — 跪姿髖屈肌伸展
  - 英文關鍵字：`kneeling hip flexor stretch`
  - 備註：骨盆後傾是關鍵，避免凹腰塌腹

- [~] **band** — 彈力帶輔助髖屈伸展

  - 備註：較不常見動作，**優先查證**
  - 處理：已從網頁移出；待找到復健/物理治療來源再回補。

### chest 胸大肌

- [ ] **hands** — 門框胸大肌伸展
  - 英文關鍵字：`doorway pec stretch` / `doorway chest stretch`
  - 備註：手肘高度可調整伸展不同纖維方向

- [~] **ball** — 胸前肌肉靠牆按摩球
  - 英文關鍵字：`pec ball release against wall`
  - 備註：避開鎖骨、胸骨、女性乳房組織
  - 處理：已從網頁移出；胸前按壓位置較敏感，需更明確的醫療/物理治療來源。

- [ ] **roller** — 胸椎開展滾筒放鬆
  - 英文關鍵字：`thoracic extension foam roller`
  - 備註：避開頸與下背

### rhomboids 菱形肌

- [ ] **hands** — 擁抱式肩胛伸展
  - 英文關鍵字：`cross-body hug stretch` / `rhomboid stretch`

- [ ] **ball** — 肩胛間靠牆按摩球
  - 英文關鍵字：`rhomboid ball release wall`
  - 備註：避開脊椎正中、肩胛骨稜角

- [~] **gun** — 筋膜槍低強度肩胛間放鬆
  - 英文關鍵字：`massage gun rhomboids` / `upper back percussion`
  - 備註：筋膜槍用法各家建議略有不同，**優先查證**
  - 處理：已從網頁移出；肩胛內側接近骨性結構與脊椎，需更明確來源。

## 查證重點優先順序

1. **筋膜槍類**（gun）：用法各家差異大，建議優先查
2. **彈力帶類**（band）：髖屈肌、肩活動度動作較少見
3. **按摩球類**（ball）：避開骨頭與神經的細節
4. **手部動作**（hands）：經典動作較不需擔心，但仍可確認步驟細節
