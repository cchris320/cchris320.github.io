# 健身模式 Form Check 設計說明

> 更新日期：2026-06-03

## 定位

健身模式的 MediaPipe form check 是「即時輔助提示」，不是醫療診斷，也不是正式教練評分。系統只用瀏覽器端的骨架偵測估算上肢動作狀態，協助使用者注意入鏡、動作幅度與手肘路徑。

影像僅在本機瀏覽器即時分析，不上傳、不錄影、不儲存。

## 支援動作

目前支援三個上肢入門動作：

| key | 動作 | 主要觀察 |
|-----|------|----------|
| `biceps_curl` | 二頭彎舉 | 手肘角度變化、手肘穩定度、上臂是否抬太高 |
| `triceps_extension` | 三頭肌伸展 | 過頭位置、伸展幅度、上臂是否靠近頭側 |
| `shoulder_press` | 肩推 | 手腕上推高度、手肘左右路徑 |

## 入鏡要求

三個動作都建議讓鏡頭拍到：

- 頭頂
- 雙肩
- 雙手肘
- 雙手腕
- 髖部

三個動作目前都要求使用者正面面向鏡頭操作。肩推與過頭三頭肌伸展需要預留頭頂上方空間，避免手舉高後超出畫面。若未來加入深蹲、弓箭步等下肢動作，才需要把「全身入鏡」列為必要條件。

## 偵測資料

系統使用 MediaPipe Pose Landmarker Lite 的 2D landmark，主要讀取：

- 肩：`11`, `12`
- 肘：`13`, `14`
- 腕：`15`, `16`
- 髖：`23`, `24`

目前不使用影像上傳、伺服器分析、錄影或歷史資料保存。

## 判斷原則

判斷邏輯刻意保持保守，只做「提示」而不是「通過/不通過」評分。

- 用 2.5 秒滑動視窗估算最近一段動作變化，並以 10%/90% 修剪後範圍降低單一壞幀造成的誤判。
- 手肘穩定度看「手肘相對肩膀」的位置變化，而不是直接看畫面上的絕對座標，避免身體小幅晃動被誤判成手肘飄移。
- 用上半身尺度（肩寬與軀幹高度取較穩定者）做比例化，降低側身或肩寬投影縮小造成的偏差。
- 選擇較清楚的一側手臂作為追蹤目標。
- 使用左右手 hysteresis，避免偵測在左右手之間頻繁跳動。
- 骨架 overlay 與分析邏輯分開處理：預設顯示完整上半身骨架，方便觀察整體偵測；目前不支援側身 form check，側身或遮擋時可能出現模型推測點，因此展示與使用都要求正面操作。
- 使用肩寬投影相對軀幹高度、最小肩寬，以及左右肩肘投影重疊程度做側身提示；連續多幀明顯偏側身時，警示使用者轉向正面，並暫停顯示手臂線條，只保留軀幹參考線。
- 攝影機預覽會同步使用 video 原始比例，避免螢幕用 CSS 裁切後和 MediaPipe 實際分析範圍不一致。
- 回饋分為 `info`、`warn`、`good` 三級，避免在使用者剛準備動作時直接判錯。

## 目前閾值

| 動作 | 指標 | 目前值 | 說明 |
|------|------|--------|------|
| 二頭彎舉 | 最小角度變化 | `45°` | 彎舉幅度需明顯變化 |
| 二頭彎舉 | 手肘位移上限 | `0.28 * 上半身尺度` | 手肘相對肩膀應盡量穩定，避免大幅離開身體兩側 |
| 二頭彎舉 | 上臂抬高上限 | `0.22 * 上半身尺度` | 避免把手肘抬到肩膀上方代償 |
| 三頭肌伸展 | 最小角度變化 | `35°` | 伸直與回收需有明顯差異 |
| 三頭肌伸展 | 過頭位置 | `手肘與手腕接近肩膀上方` | 先確認是過頭三頭肌伸展，而不是一般手臂彎伸 |
| 三頭肌伸展 | 手肘位移上限 | `0.38 * 上半身尺度` | 過頭動作允許較多調整，但仍提醒上臂固定在頭側 |
| 肩推 | 手腕行程 | `> 0.5 * 軀幹高` | 需有明顯上推行程 |
| 肩推 | 過頭位置 | `手腕高於肩膀約 0.1 * 軀幹高` | 判斷是否真的推到肩上方 |
| 肩推 | 手肘左右偏移上限 | `0.6 * 上半身尺度` | 路徑太左右飄時提醒穩定上推 |

這些值是展示用的保守門檻，不代表標準訓練處方。若實測發現特定動作容易誤警告，優先調整「提醒門檻」而不是改成絕對對錯。

## 限制

- 只看上肢 landmark，無法完整評估核心穩定、足部站姿、膝蓋或髖部控制。
- Lite 模型在光線不足、身體被裁切、手臂遮擋或鏡頭太遠時會抖動。
- MediaPipe 可能推測被身體遮住的關節位置；目前不把側身或遮擋狀態納入支援範圍，使用者應正面面向鏡頭操作。
- 目前不做次數統計、不做重量建議、不做疼痛判斷。
- 系統不應輸出「姿勢正確/錯誤」這類絕對結論，只提供可調整方向。

## 未來擴充

若要加入側平舉、划船等上肢動作，可優先沿用肩、肘、腕的比例化判斷。若要加入深蹲、弓箭步、橋式等下肢或全身動作，需另外設計髖、膝、踝角度與全身入鏡要求，不能直接套用目前上肢規則。
